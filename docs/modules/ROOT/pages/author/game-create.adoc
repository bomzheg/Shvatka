= Как создать игру

Писать игры может игрок с xref:player/promotion.adoc[аппрувом].

В боте и на сайте игра собирается по-разному. В боте уровни пишутся отдельно,
а потом привязываются к игре. На сайте уровни живут внутри игры: сначала
создаётся игра, а уровни пишутся прямо в ней.

Данные общие, так что игру можно начать писать в боте, а дописать на сайте
(и наоборот).

== В боте

=== Шаг 1. Написать уровни

`/new_level` — бот проведёт по всем шагам создания уровня. Подробно:
xref:author/level-create.adoc[Как написать уровень].

Уровень, не привязанный ни к какой игре, называется "свободным" — именно
из свободных уровней и собирается новая игра.

=== Шаг 2. Собрать игру

`/new_game` (или главное меню -> "🗂Мои игры" -> "✍Написать игру")

.Список своих игр: тут же кнопки "Написать игру", "Написать уровень" и "Уровни"
image::{attachmentsdir}/author/tg-my-games.png[]

1. Бот попросит название игры
+
.Выбор названия игры
image::{attachmentsdir}/author/tg-new-game-name.png[]
+
2. Дальше — список свободных уровней с галочками. Отметь те, что войдут в игру
+
.Выбор уровней для новой игры
image::{attachmentsdir}/author/tg-new-game-levels.png[]
+
3. Нажми "Сохранить"

WARNING: Название игры и ID уровней попадают в лог-файлы, которые читает
системный администратор. Не пиши в них ключи, локации и прочие спойлеры.

=== Шаг 3. Проверить

Главное меню -> "🗂Мои игры" -> выбрать игру. В карточке игры видно статус,
количество уровней и время старта.

.Карточка игры
image::{attachmentsdir}/author/tg-game-menu.png[]

.Что можно сделать из карточки игры
* "📜Сценарий" — посмотреть и изменить состав уровней
* "👥Организаторы" — xref:author/game-orgs.adoc[добавить оргов и настроить им полномочия]
* "✏Переименовать" — сменить название
* "📆Запланировать игру" — xref:author/game-schedule.adoc[назначить дату и время]
* "📝Начать сборку вейверов" — открыть сбор заявок
* "📦zip-сценарий" — выгрузить игру файлом
* "🔑🧾Все ключи в xlsx" — таблица со всеми ключами игры
* "🔑🖨Ключи для печати" — pdf с ключами для печати на A4
* "🔀Переходы" — схема переходов между уровнями

=== Загрузить готовую игру из zip

Если игра уже есть в виде zip-сценария (например, выгружена из другой игры
или подготовлена заранее): `/new_game` -> "Загрузить из zip" -> прислать файл.

== На сайте

=== Создать игру

Раздел "Мои игры" (`/games/constructor`) -> поле "Название новой игры"
-> "Создать". Игра появится в списке ниже.

=== Редактировать игру

Клик по игре в списке открывает полноценный редактор, где
на одной странице собрано всё:

.Редактор игры: старт, название, организаторы, уровни и файлы на одной странице
image::{attachmentsdir}/author/web-game-editor.png[]

* название и планируемый старт
* автор игры
* уровни: добавление, порядок (стрелки или drag-and-drop), удаление
* внутри уровня — ключи, ключи с эффектами, таймеры с эффектами,
подсказки по времени
* файлы игры (картинки, видео, аудио) с загрузкой и переименованием
* организаторы и их полномочия
* блок "Ошибки проверки" — что мешает сохранить игру

Не забывай нажимать "Сохранить".

=== Запустить

В шапке редактора появляется кнопка, которая переводит игру в следующий статус:
"Начать сбор вейверов" у игры в процессе создания, "Опубликовать игру"
у сыгранной.
Какая именно кнопка есть — зависит от статуса игры.

== Статусы игры

в процессе создания (`underconstruction`)::
Черновик, можно менять всё.

сбор вейверов (`getting_waivers`)::
Команды подают заявки. Сценарий ещё можно править.

началась (`started`)::
Идёт игра. Все редакторы заблокированы.

все команды финишировали (`finished`)::
Игра сыграна, доступны результаты и лог ключей.

завершена (`complete`)::
Игра закрыта, получила свой номер и уехала в архив прошедших игр. Именно этот
статус делает игру публичной: сценарий, лог ключей и результаты становятся
видны любому игроку, без всяких полномочий орга.

== Перед игрой

Обязательно пройдись по
xref:author/author-check-list.adoc[чек-листу автора] — он короткий и спасает
от самых обидных ошибок.
