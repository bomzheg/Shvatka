= Как добавить уровни в игру

Уровень, написанный в боте, сначала не входит ни в одну игру — такой уровень
называется свободным. В игру добавляются именно свободные уровни, причём
порядок добавления = порядок прохождения.

На сайте отдельных свободных уровней нет: там уровни пишутся сразу внутри игры,
см. xref:author/game-create.adoc[Как создать игру].

== В боте

Главное меню -> "🗂Мои игры" -> выбрать игру -> "📜Сценарий".

уровни из игры и добавить заново в нужной последовательности — или
воспользоваться веб-редактором, где есть стрелки и drag-and-drop.

Клик по уровню в списке::
Открывает меню уровня: посмотреть ("📂Показать"), отредактировать,
"🗑Убрать из игры".

Убранный из игры уровень снова становится свободным и никуда не пропадает.

TIP: Кнопка "📜Сценарий" доступна, только пока игру можно редактировать —
то есть до старта.

== На сайте

"Мои игры" -> открыть игру -> блок "Уровни".

* "+ Уровень" — добавить уровень
* ⬆ и ⬇ у каждого уровня или drag-and-drop за ручку слева — переставить его
в нужное место
* 🗑 — убрать уровень из игры

Номер уровня в игре = его позиция в этом списке. После перестановок
нажми "Сохранить".

== Проверка перед игрой

* Убедись, что уровни идут в правильном порядке
* По кнопке "📂Показать" проверь, что уровень выходит целиком и все медиафайлы
отправляются как надо
* Уровни, написанные на сайте, проверь через бота, а написанные в боте —
через сайт: отображение может отличаться
* Если в игре есть переходы между уровнями, посмотри кнопку "🔀Переходы" —
там схема, кто куда может попасть, и `🔑🧾Все ключи в xlsx` со всеми ключами игры
* Чтобы раздать ключи оргам на точках, возьми `🔑🖨Ключи для печати`: pdf для
печати на A4. Каждый ключ подписан названием и датой игры и повторён столько
раз, сколько влезло на лист — распечатать и разрезать

Полный список проверок — в xref:author/author-check-list.adoc[чек-листе автора],
а про нелинейные схемы — в xref:author/level-howto.adoc[способах использования].
