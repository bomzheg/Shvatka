= Как написать уровень

Перед тем как что-то нажимать, стоит прочитать
xref:author/level-concept.adoc[введение в описание уровня] — что такое подсказки,
ключи, таймеры и эффекты. Здесь — только про то, куда нажимать.

== В боте

Отправь `/new_level` (или главное меню -> "🗂Мои игры" -> "✍Написать уровень").

=== Шаг 1. ID уровня

Короткое имя из цифр и латинских букв, например `corner` или `lvl_1`.
Оно нужно только автору: по нему уровни выстраиваются в игру и на него
ссылаются переходы.

WARNING: ID уровня попадает в лог-файлы, которые читает системный администратор.
Не зашивай в него ключ или локацию.

.Запрос ID уровня
image::{attachmentsdir}/author/tg-level-id.png[]

=== Шаг 2. Меню уровня

Дальше бот показывает меню, где видно текущее состояние уровня: сколько ключей,
ключей с эффектами и таймеров задано и какие подсказки уже есть.

.Меню написания уровня
image::{attachmentsdir}/author/tg-level-menu.png[]

.Кнопки меню
🔑Ключи::
Пришли ключи одним сообщением, каждый с новой строки:
+
....
СХСЛОВО1
СХСЛОВО2
СХСЛОВО3
....
+
Это мастер-ключ уровня — то, что уровень завершает. Мастер-ключ у уровня
может быть только один, но состоять он может из нескольких ключей: тогда
уровень завершится, когда команда введёт их все, в любом порядке.
+
TIP: Нет никакой необходимости делать составные ключи как в старом движке типа `СХ1СЛОВОСХ2ДРУГОЕСХ3ТРЕТЬЕ`
+
.Ввод ключей уровня
image::{attachmentsdir}/author/tg-level-keys.png[]

✨Ключи с эффектами::
Кнопка появляется, когда обычные ключи уже введены. Внутри: "➕Добавить"
-> задать ключи -> задать эффекты (бонус/штраф в минутах, подсказка,
завершение уровня, переход на конкретный уровень) -> "✅Готово".
+
.Список ключей с эффектами
image::{attachmentsdir}/author/tg-effects-keys.png[]
+
.Редактор эффектов: подсказки, бонус/штраф, завершение уровня и переход
image::{attachmentsdir}/author/tg-effects.png[]

🕑Таймеры::
Время от начала уровня и эффекты, которые в это время сработают.
Добавляются так же: "➕Добавить" -> время -> эффекты.
+
.Таймеры уровня
image::{attachmentsdir}/author/tg-level-timers.png[]

💡Подсказки::
Список подсказок по времени, см. ниже.

✅Готово, сохранить::
Кнопка появляется, только когда уровень корректен: есть хотя бы одна подсказка
и есть ключ или таймер, завершающий уровень. Пока чего-то не хватает, бот
пишет, чего именно.

=== Шаг 3. Подсказки

"💡Подсказки" -> "➕Добавить подсказку":

1. Выбери время выхода подсказки кнопкой или пришли число минут сообщением
+
.Выбор времени выхода подсказки
image::{attachmentsdir}/author/tg-hint-time.png[]
2. Присылай боту сообщения — текст, фото, видео, аудио, гифки, кружочки,
голосовые, документы, стикеры, геолокацию, контакт. Всё, что прислал, войдёт
в одну подсказку
3. Нажми "✅К следующей подсказке"
+
.Наполнение подсказки: присылай сообщения, пока не будет готово
image::{attachmentsdir}/author/tg-hint-content.png[]

Подсказка на 0 минут — это загадка уровня, отправная точка. Она обязательна,
и уровень должен разгадываться по одной только загадке.

Уже добавленную подсказку можно открыть и отредактировать: изменить время,
удалить отдельную часть подсказки (🗑 напротив неё), добавить ещё, либо удалить
подсказку целиком.

.Список подсказок уровня
image::{attachmentsdir}/author/tg-level-hints.png[]

=== Шаг 4. Проверить, как выглядит

Главное меню -> "🗂Мои игры" -> "🗂Уровни" (или команда `/levels`)
-> выбрать уровень:

* "📂Показать" — бот пришлёт уровень целиком, ровно так, как его увидят игроки
* "✏Редактирование" — вернуться к правкам
* "🗑Убрать из игры" / "🗑Удалить"

.Меню уровня

== На сайте

Уровни живут внутри редактора игры: "Мои игры" -> открыть игру -> блок "Уровни"
-> "+ Уровень".

.Раскрытая карточка уровня: ключ, ключи с эффектами, таймеры и подсказки по времени
image::{attachmentsdir}/author/web-level-editor.png[]

.У каждого уровня раскрывается карточка, где есть всё сразу
* ID уровня
* ключи (в одну строку через пробел, например `SH123 SH321`)
* "Ключи с эффектами" — по кнопке "+ Ключ"
* "Таймеры с эффектами" — по кнопке "+ Таймер"
* "Подсказки по времени" — по кнопке "+ Время", внутри собирается содержимое
подсказки: текст, картинки, видео и прочее
* стрелки ⬆⬇ — порядок уровней в игре, корзина — убрать уровень

Файлы (картинки, видео, аудио) загружаются в блоке "Файлы" и потом вставляются
в подсказки.

=== Форматированное сообщение

Кроме обычных частей подсказки (текст, фото, видео и прочих) есть тип
"Форматированное сообщение" — это rich message Telegram: заголовки, списки,
таблицы, цитаты и вложения в одном сообщении. Собрать такую подсказку можно
только на сайте, в боте её не составить.

.В редакторе такой части подсказки два поля
* "Разметка" — сам текст на Rich HTML (или на Markdown, если выбрать его
в "Языке разметки")
* "Вложения" — файлы, которые встают внутрь разметки. У каждого вложения есть
идентификатор, а рядом показана готовая вставка (+`<img src="media1">`+) —
скопируй её в нужное место разметки

Игрокам бот пришлёт такую подсказку одним форматированным сообщением. На сайте
она показывается так же — кроме разметки на Markdown, её сайт показывает как
есть, без оформления.

Внизу редактора есть блок "Ошибки проверки" — если игра не сохраняется,
причина будет там.
