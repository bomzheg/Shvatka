= Создание команды

Для создания команды достаточно просто нажать на предложенную ботом команду `/create_team`

NOTE: Создавать команду может только модератор чата, у которого есть
xref:player/promotion.adoc[аппрув]. И только в супергруппе — см.
xref:setup_team/check_is_sg.adoc[как отличить группу от супергруппы].

== Добавление игроков
Добавление игроков может занять некоторое время, поскольку на сообщение каждого необходимо отправить команду `/add_in_team` ответом на сообщение пользователя

.Добавление игроков в команду
video::{attachmentsdir}/team/tg-add-player.mp4[opts=autoplay,loop,nocontrols,nofullscreen,muted]

К сожалению, бот не может получить доступ к списку участников чата, чтобы автоматизировать этот не интересный, но к счастью одноразовый процесс

Есть и другие способы: кнопкой при входе игрока в чат, из капитанского мостика
и через сайт — все они описаны в
xref:setup_team/add_players.adoc[инструкции по добавлению игроков].

== Команда без telegram-чата

Команду можно создать и на сайте: раздел "Команда" -> "Создать команду".
Такая команда сразу может играть через сайт, а telegram-чат к ней капитан
привяжет позже — см.
xref:setup_team/move_chat.adoc[Как перенести команду в другой чат].
