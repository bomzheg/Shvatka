= Как перенести команду в другой чат

Команда привязана к одному чату telegram: именно туда во время игры приходят
уровни и подсказки, и именно там команда вводит ключи.

.Перенести команду в другой чат может понадобиться, если:
* нужен чат на одну игру — например, когда команда делится на две команды
на игру, чтобы не выгонять всех из общего командного чата
* команда переехала в новый чат, а старый забросили
* команду создали на сайте, и telegram-чата у неё ещё нет

Переносить команду может *только капитан*.

== Что нужно подготовить

1. Целевой чат должен быть супергруппой
(см. xref:setup_team/group2sg.adoc[Преобразование группы в супергруппу]
и xref:setup_team/check_is_sg.adoc[Как отличить группу от супергруппы])
2. В целевом чате должен быть бот
3. В целевом чате должно быть хотя бы одно сообщение — так бот узнает о чате
4. В целевом чате не должно быть другой команды

== Как перенести

1. В личке с ботом отправь `/manage_team`
2. В капитанском мостике нажми "🔀Перенести в другой чат"
+
.Капитанский мостик
image::{attachmentsdir}/team/tg-bridge-main.png[]
+
3. Бот попросит нажать кнопку в самом низу экрана — это специальная кнопка
telegram для выбора чата
4. Выбери нужный чат

Бот подтвердит перенос в личке.

== Что происходит со старым чатом

Ничего страшного: он просто перестаёт быть чатом команды. Бот из него не выходит
сам, при желании его можно удалить из чата вручную. Состав команды, вейверы,
сыгранные игры и статистика — всё остаётся, они привязаны к команде, а не к чату.

== Частые проблемы

Чат почему-то не найден::
Бот ещё ничего не знает про этот чат. Добавь бота в чат, напиши в чат любое
сообщение и повтори перенос.

Чат не супергруппа::
Сначала xref:setup_team/group2sg.adoc[преобразуй группу в супергруппу].

В чате уже есть другая команда::
Один чат — одна команда. Возьми другой чат либо разберись с командой,
которая там уже есть.

Кнопки "🔀Перенести в другой чат" нет / ничего не происходит::
Переносить команду может только капитан. Заместители, даже со всеми полномочиями,
этого сделать не могут.

== Во время игры переносить нельзя

Пока идёт игра, управление командой в боте выключено — уровни продолжат
приходить в текущий чат. Переносить команду нужно заранее, до старта.
