= Полномочия в команде

Капитан может всё. Чтобы не быть единственной точкой отказа, часть своих
обязанностей он может раздать другим игрокам команды — они станут
"заместителями капитана".

Полномочия выдаются каждому игроку отдельно, в любом сочетании.

== Где выдавать

.В боте
`/manage_team` -> "👥Игроки" -> выбрать игрока. У каждого полномочия своя кнопка,
нажатие переключает его вкл/выкл.

.Список игроков в команде

.Управление конкретным игроком

.На сайте
Раздел "Команда" -> у нужного участника нажать карандашик -> блок "Права".
Там же видно текущие права каждого участника в виде значков.

== Какие бывают полномочия

Подавать вейверы (`can_manage_waivers`)::
Может запускать сбор вейверов командой `/waivers` в чате команды и утверждать
итоговый список `/approve_waivers`. Полезно, если капитан не всегда в сети
в момент сбора. Подробнее: xref:setup_team/waivers.adoc[Вейверы].

Управлять игроками (`can_manage_players`)::
Может открывать список игроков команды, менять им должности и emoji,
а так же раздавать полномочия дальше. Это самое "сильное" полномочие,
выдавай его только тем, кому доверяешь как себе.

Переименовывать команду (`can_change_team_name`)::
Может менять название команды и её девиз.

Добавлять игроков (`can_add_players`)::
Может принимать в команду новых людей всеми способами
из xref:setup_team/add_players.adoc[инструкции по добавлению игроков].

Исключать игроков (`can_remove_players`)::
Может выгонять игроков из команды.

== Что остаётся только капитану

* xref:setup_team/move_chat.adoc[Перенести команду в другой чат]
* Привязать к команде её "былые свершения" (команду с форума)

== Должность и emoji

Кроме полномочий у игрока есть должность (водитель, полевой, мозг, штурман…)
и emoji. Ни на что в движке они не влияют — это украшение, которое видно
в списке игроков, в вейверах и в карточке команды. Меняются там же,
где и полномочия: кнопки "Изменить должность" и "Изменить emoji" в боте
или поля "Роль" и "Emoji" на сайте.

== Частые вопросы

Могу ли я выдать полномочия сразу всем?::
Нет, только по одному игроку. Зато это делается один раз и надолго.

Заместитель может выдать полномочия сам себе?::
Нет, менять собственные полномочия нельзя никому, кроме как через капитана.
Зато обладатель полномочия "Управлять игроками" раздаёт полномочия
всем остальным игрокам команды — поэтому выдавай его осознанно.

Я выгнал игрока, а он был в вейверах::
Если идёт сбор вейверов на игру, при исключении игрока его вейвер и голос
удаляются автоматически.
