= Сбор вейверов

В какой-то момент в канале схватки появляется сообщение о начале сбора вейверов


.Сообщение о начале сбора вейверов
image::{attachmentsdir}/team/tg-notification-start-waivers.png[]
Капитаны или назначенные в установленном порядке заместители команд, которые хотят сыграть, должны отправить в чаты своих команд `/waivers`


.Сборка вейверов
image::{attachmentsdir}/team/tg-waivers-start.png[]
После этого, игроки, включая капитана, могут нажимать кнопки под сообщением, чтобы отметиться, кто хочет играть, кто не хочет, и кто ещё не решился


.Сборка вейверов, с участвующими игроками
image::{attachmentsdir}/team/tg-waivers-poll.png[]
После того как команда определилась капитан в личке с ботом отправляет `/approve_waivers`


.Утверждение вейверов капитаном
image::{attachmentsdir}/team/tg-waivers-approve.png[]
Здесь капитан ещё раз может проверить, что список вейверов верный. По клику на кнопку с игроком — игрок удаляется из вейверов.

По нажатию "добавить игрока принудительно" открывается меню, в котором можно добавить нужных игроков команды, которые ещё не проголосовали

После завершения всех манипуляций следует нажать "подтвердить вейверы" — тогда они сохранятся в движке и будут направлены оргам


.После нажатия "подтвердить вейверы" в личке с ботом
image::{attachmentsdir}/team/tg-waivers-approved-dm.png[]

.Финальный список вейверов после утверждения капитаном (уже без кнопок)
image::{attachmentsdir}/team/tg-waivers-approved-team.png[]
При необходимости изменить вейверы — капитан снова отправляет в чат команды `/waivers` и процесс повторяется с начала

== Кто кроме капитана может подавать вейверы

Всё то же самое может делать любой игрок команды с полномочием
"Подавать вейверы" (см. xref:setup_team/permissions.adoc[Полномочия в команде]).
Удобно, если капитан не всегда в сети: сбор не встанет из-за одного человека.

Остальные игроки могут только голосовать кнопками под сообщением. На попытку
нажать управляющие кнопки бот ответит "Недостаточно прав".

== Вейверы через сайт

Пока идёт сбор вейверов, на сайте в разделе "Текущая игра" отображается
список всех команд с их вейверами, а так же твой собственный статус:
будешь ли ты играть.

Если у тебя есть полномочие подавать вейверы, там же появится кнопка
"Подать вейверы команды": откроется окно со списком игроков команды,
где галочками отмечаются те, кто играет, и нажимается "Опубликовать".

Это альтернатива паре `/waivers` + `/approve_waivers`: список сразу уходит оргам,
голосование в чате при этом не требуется.

== Частые вопросы

Игрок не проголосовал, а играть будет::
На экране утверждения нажми "добавить игрока принудительно" и выбери его.
На сайте — просто отметь его галочкой.

Игрок передумал после утверждения::
Отправь `/waivers` ещё раз и повтори процедуру — новый утверждённый список
заменит старый.

Бот удалил сообщение с голосованием::
Так и задумано: при повторном `/waivers` или при переходе к утверждению
старое сообщение убирается, чтобы никто не голосовал в устаревшем.
