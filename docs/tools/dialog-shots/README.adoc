= Скриншоты диалогов бота для документации

Скриншоты бота в документации сделаны не руками, а из preview-страницы
aiogram_dialog: она рендерит каждое окно каждого диалога как сообщение telegram
с инлайн-клавиатурой, подставляя `preview_data` из описания диалогов.
Значит, при изменении диалогов скриншоты можно просто перегенерировать.

== Шаг 1. Получить preview-страницу

Отрендерить preview всех диалогов бота (`aiogram_dialog.tools.preview`,
`render_preview`) в html-файл, например `preview.html`.

Тексты и кнопки на странице — настоящие, из описаний диалогов; данные —
из `preview_data` соответствующих окон (см. `shvatka/tgbot/dialogs/preview_data.py`).

== Шаг 2. Наснимать скриншоты

[source,shell]
----
npm install playwright
node shoot.mjs preview.html shots.json ../../modules/ROOT/attachments
----

`shots.json` — это соответствие `StateGroup:state` -> путь картинки внутри
`attachments`. Скрипт открывает страницу в chromium, для каждого состояния
переходит по якорю и снимает пузырь сообщения вместе с небольшим полем
вокруг него.

Состояния, которых нет в preview, скрипт пропускает с пометкой `SKIP`
и завершается с кодом 1 — удобно замечать, что диалог переименовали.

== Замечания

* Шрифт: страница просит Roboto из Google Fonts. Без сети скриншоты
получатся системным шрифтом — это не страшно, но менее похоже на telegram.
Для повторяемости можно один раз вшить woff2 в html как data-uri.
* Эмодзи: нужен установленный шрифт с цветными эмодзи (например
`fonts-noto-color-emoji`), иначе вместо них будут квадратики.
* Скрипт прячет служебную подпись состояния (preview рисует её на месте
времени сообщения) и подставляет в качестве имени бота "Схватка".
