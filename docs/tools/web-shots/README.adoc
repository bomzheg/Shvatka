= Скриншоты веб-интерфейса для документации

Веб-скриншоты в документации сняты с настоящего фронтенда
(https://github.com/bomzheg/shvatka-ui[bomzheg/shvatka-ui]), но без настоящего
бэкенда: вместо него поднимается `mock-api.mjs` — заглушка REST API, которая
отдаёт заранее заготовленные данные (команда Пони, игра "Схватка это чудо",
уровни pinky_pie / fluttershy / rainbow — те же, что в preview диалогов бота).

Так скриншоты получаются повторяемыми и не зависят от состояния тестового стенда.

== Шаг 1. Собрать фронтенд

[source,shell]
----
cd shvatka-ui
npm install
----

Дальше нужно, чтобы приложение обращалось к заглушке. В `src/assets/env.js`
пропиши:

[source,js]
----
window["env"]["apiUrl"] = "http://127.0.0.1:8099";
window["env"]["cdnUrl"] = "http://127.0.0.1:8099/cdn";
window["env"]["mainUrl"] = "http://127.0.0.1:4300";
----

и собери прод-сборку:

[source,shell]
----
npx ng build --configuration production
----

[NOTE]
====
Именно прод-сборку, а не `ng serve`. Конфигурация `development` в `angular.json`
подменяет `src/app/http/http.adapter.ts` на `src/tests/http/dev.http.adapter.ts`,
а тот отстал от основного адаптера (нет `del`, `getBlob`, другая сигнатура
`postWithoutCookies`) — и `ng serve` не компилируется. Если это когда-нибудь
починят, шаг можно упростить.
====

== Шаг 2. Поднять заглушку и статику

[source,shell]
----
node mock-api.mjs &                        # REST-заглушка на :8099
npx http-server dist/shvatka/browser -p 4300 --proxy http://127.0.0.1:4300? &
----

Подойдёт любой статический сервер, умеющий отдавать `index.html` на неизвестные
пути (SPA-роутинг).

== Шаг 3. Наснимать скриншоты

[source,shell]
----
node shoot-web.mjs shots-web.json ../../modules/ROOT/attachments
MODE=waivers node mock-api.mjs &           # игра в статусе "сбор вейверов"
node shoot-web.mjs shots-web-waivers.json ../../modules/ROOT/attachments
----

`shots-web.json` — список снимков: адрес страницы, куда положить картинку,
какие элементы перед съёмкой раскрыть (`clicks`) и что именно снимать
(`clip` — селектор; без него снимается страница целиком).

Скрипт открывает страницы в chromium с русской локалью и московским временем,
блокирует внешний виджет telegram и прячет "липкую" шапку, когда снимает
отдельный блок.

NOTE: Chromium запрашивается как `channel: "chromium"` — по умолчанию playwright
может взять headless shell, на котором приложение падает.

== Данные заглушки

Все временные метки в `mock-api.mjs` считаются от текущего момента, поэтому
счётчики вида "уровень начался 17 минут назад" выглядят правдоподобно в любой
день. Переменная окружения `MODE=waivers` переводит игру в статус сбора вейверов —
так снимается блок вейверов, которого во время игры уже нет.
