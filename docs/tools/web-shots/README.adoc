= Скриншоты веб-интерфейса для документации

Веб-скриншоты в документации сняты с настоящего фронтенда
(https://github.com/bomzheg/shvatka-ui[bomzheg/shvatka-ui]), но без настоящего
бэкенда: вместо него фронтенд поднимается против заглушки REST API, которая
живёт там же — `tools/mock-api/`. Заглушка отдаёт заготовленные данные (команда
Пони, игра "Схватка это чудо", уровни pinky_pie / fluttershy / rainbow — те же,
что в preview диалогов бота).

Так скриншоты получаются повторяемыми и не зависят от состояния тестового стенда.

== Шаг 1. Поднять интерфейс с заглушкой

[source,shell]
----
cd shvatka-ui
npm install
npm run mock        # заглушка API на :8099
npm run start:mock  # ng serve на :4200, /api уходит в заглушку
----

== Шаг 2. Наснимать скриншоты

[source,shell]
----
cd Shvatka/docs/tools/web-shots
npm install playwright
node shoot-web.mjs shots-web.json ../../modules/ROOT/attachments
----

Затем то же самое для блока вейверов — его видно только пока игра в статусе
сбора вейверов:

[source,shell]
----
# в shvatka-ui, вместо обычного npm run mock
MODE=waivers npm run mock
----

[source,shell]
----
node shoot-web.mjs shots-web-waivers.json ../../modules/ROOT/attachments
----

`shots-web.json` — список снимков: адрес страницы, куда положить картинку,
какие элементы перед съёмкой раскрыть (`clicks`) и что именно снимать
(`clip` — селектор; без него снимается страница целиком).

Адрес интерфейса берётся из переменной `UI_URL` (по умолчанию
`http://localhost:4200`).

Скрипт открывает страницы в chromium с русской локалью и московским временем,
блокирует внешний виджет telegram и прячет "липкую" шапку, когда снимает
отдельный блок.

NOTE: Chromium запрашивается как `channel: "chromium"` — по умолчанию playwright
может взять headless shell, на котором приложение падает.

== Когда переснимать

* поменялась вёрстка или тексты интерфейса
* поменялись данные заглушки в `tools/mock-api/mock-api.mjs`
* поменялись подписи, которые видно на скриншотах — например названия
полномочий: они одни и те же в боте, в интерфейсе и в этой документации
